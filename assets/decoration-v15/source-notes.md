# Decorative asset credits

The peripheral lattice uses `background-trianglemesh.png` from the user-supplied In Falsus UI asset pack. The chapter emblem uses the user-supplied `story.webp`. These are third-party reference assets associated with In Falsus / lowiro, not portfolio artworks created by the applicant. The files are copied unchanged with their original transparency; layout, masking and display size are handled in CSS.

The larger scattered fragments and short pointer trail are drawn in code for this website. Their shapes and sparse arrangement reference the supplied red/blue scatter images. Those scatter images are not layered over the page, so they do not add a hidden field of extra particles. The supplied `bg-cards.webp` was considered as a visual reference only; its character artwork is not displayed as portfolio work.

This source record does not claim that the UI pack's cursor-specific licence covers every asset. The original pack and source ownership remain separate from this website's implementation.
